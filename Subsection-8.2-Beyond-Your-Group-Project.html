8.2 Beyond Your Group Project

The skills in this tutorial work in every Discord server, not just your group project. This page explains how to use them in clubs and future classes.

Student Organizations and Future Classes

Your group project is only the start. Student organizations and future classes at UCF may also invite you to a Discord server, and every skill you practiced here works the same way there.

Finding a student organization

KnightConnect is UCF's official involvement platform, where you can explore over 600 Registered Student Organizations and view upcoming events. Each organization has its own page with meeting times, contact information, and ways to get involved. Log in with your NID and NID password to see every organization, as the Office of Student Involvement explains.

If a club you join uses Discord, ask an officer for the invite link, and then join the server the same way you joined your group's server in Subsection 3.2.

Using your skills in a new server

  • Set a nickname: Use a server nickname with your real name in class servers, and a different one in hobby clubs if you want.
  • Control your alerts: Clubs can be busy. Set each new server to Only @mentions in Subsection 6.1 so club chat does not bury class deadlines.
  • Read the rules first: Most servers have a rules or announcements channel. Read it before you post, just like you check pinned messages in Subsection 5.3.
  • Use the same meeting habits: The etiquette in Subsection 7.3 works for club meetings, study sessions, and officer calls.
  • Protect your privacy: Large servers include people you do not know. Keep the message and friend request limits from Subsection 6.2 turned on.

Future classes

When a new professor or project group invites you to a Discord server, you do not need to start over. You already know how to join from an invite link, find the right channel, mention a teammate, share a file, and join a meeting. When a semester ends, you can leave servers you no longer need so your server list stays short and easy to read.
